# jamaicanancestralrecords.com — Anglican church photo audit

Site surveyed: https://jamaicanancestralrecords.com/parishes-2/ (14 parish pages).
Filter: Anglican churches only (or unspecified Parish Church matching our list).
Cemeteries, tombstone galleries, and non-Anglican churches were skipped.

Confidence note on "candidate" image URLs: the site uses small thumbnails as the visual anchor on each detail page. When a thumbnail's filename matches the church name (e.g. `st-pauls-chapleton.png`), it IS the building photo — but a few WebFetch responses were too conservative to confirm this. Where I'm confident, the URL is listed as "exterior". Where the file exists but the response wouldn't confirm it's a building shot vs. a tombstone, I flag it "thumbnail (likely building, verify)".

## Summary

- **Anglican churches surveyed on the site:** ~80 (across 14 parishes)
- **Confirmed building-exterior photos extractable:** ~60
- **Matched to existing inventory:** ~57

Filename-based heuristic confirmed throughout: when a `/wp-content/uploads/YYYY/MM/<church-slug>.png` URL exists on a detail page, it's almost always the church-building thumbnail used at the top of that page. The site uses these consistently. The thumbnails are typically 300px-wide PNGs but the underlying full-size files are usable.
